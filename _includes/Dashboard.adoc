O menu está sempre acessível a partir da vista principal do MONARC:

1. Para chegar ao _Dashboard_, primeiro clique no menu contextual image:Menu.png[pdfwidth=3%,width=3%] no canto superior direito.
+
[#fig-dashboard-1-800]
.Acesso ao _Dashboard_ através do menu contextual
image::Dashboard_1_800.png[Dashboard - menu contextual]

2. Depois, no menu pendente, escolha _Dashboard_.
+
[#fig-dashboard-2-800]
.Seleção de _Dashboard_ no menu pendente
image::Dashboard_2_800.png[Menu Contextual Dashboard]

A vista _Dashboard_ mostra informação sobre os seguintes tópicos:

*	Riscos
*	Ameaças
*	Vulnerabilidades
*	Cartografia
*	Conformidade

NOTE: A maioria dos gráficos têm parâmetros e são exportáveis.

[#fig-dashboard-3-800]
.Vista detalhada do _Dashboard_
image::Dashboard_3_800.png[Vista detalhada do Dashboard]

Todas as partes do _dashboard_ têm as mesmas funcionalidades.

1. _Escolher_ a parte sobre a qual é necessário um _dashboard_.
2. _Exportar_ todos os dados num documento XLSX para criar o seu próprio gráfico.
3. _Alterar_ os parâmetros do gráfico selecionado.
4. _Exportar_ o gráfico como PNG
