Para chegar ao ecrã da _Declaração de aplicabilidade_, clique no menu contextual image:Menu.png[pdfwidth=4%,width=4%] à direita:

[#fig-statementapplicability-1-800]
.Menu contextual
image::StatementApplicability_1_800.png[Menu Contextual]

Depois, no menu pendente, escolha o item de menu _Declaração de aplicabilidade_:

[#fig-statementapplicability-2-800]
.Item de menu _Declaração de aplicabilidade_
image::StatementApplicability_2_800.png[Menu Declaração de aplicabilidade]

Aparece o ecrã _Declaração de aplicabilidade_:

[#fig-statementapplicability-3-800]
.Ecrã _Declaração de aplicabilidade_
image::StatementApplicability_3_800.png[Ecrã Declaração de aplicabilidade]

1. Escolha o _Referencial_ (ISO/IEC 27002:2022, NIST Core) com o qual pretende trabalhar.
2. O _Código_ é um campo clicável; clique nele e veja todos os riscos associados ao controlo de segurança selecionado.
3. Para escolher se o controlo de segurança é incluído ou excluído, basta clicar no acrónimo. Aparecerá uma descrição ao passar o cursor sobre ele.
4. Os campos _Observações/Justificação_, _Evidências_, _Ações_ são campos de texto; basta clicar neles e preencher a célula relevante.
5. _Exportar_ a vista selecionada em CSV.
6. _Importar_ informação para o referencial selecionado a partir de outro.
7. O _Nível de conformidade_ é uma lista pendente.

Os acrónimos de inclusão/exclusão são os seguintes:

EX 	- Excluído
CO	- Obrigações contratuais
BP	- Boas práticas
LR	- Requisitos legais
BR	- Requisitos de negócio
RRA	- Resultados da avaliação de risco

Se clicar em _Importar a partir de outro referencial_, aparece o ecrã _Importar uma declaração de aplicabilidade (SOA)_:

[#fig-importsoa-1-800]
.Ecrã _Importar uma declaração de aplicabilidade (SOA)_
image::ImportSOA_1_800.png[Ecrã Importar uma declaração de aplicabilidade]

1.	Por favor, _Leia_ o texto antes de importar
2.	Escolha o _Referencial_ que contém a informação que pretende converter para o selecionado.
3.	Escolha as opções de importação
4.	Clique no botão _Importar_ para que a informação do referencial seja importada.
